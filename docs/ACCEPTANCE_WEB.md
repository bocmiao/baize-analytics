## 后续增强实测

最新真实原生应用浏览器运行已通过邀请注册/RBAC、SSE 新增事件与心跳在线数、无需外部模型的本地聚合事实快照和建议复检闭环、移动视口无页面溢出。强化 tracker 测试新增持久化 PV 断言后发现 HeadlessChrome UA 被生产机器人过滤为 204，测试已改为模拟正常 Chrome 用户代理，生产过滤与断言保持启用。SSE 心跳在线数刷新修正为合并刷新；单项实际通过。中间完整复跑 11 通过，回放项登录遇生产 HTTP 429（同分钟累积登录），未放宽限制；自然窗口后完整复跑 12 passed (23.7 s)。

新增实例管理员 GeoIP 设置表单调用安全保存/官方下载校验 API，未配置真实官方账号，不声明下载已实测。历史币种未知时收入显示已知部分及覆盖率警告，不显示虚假的完整金额。
