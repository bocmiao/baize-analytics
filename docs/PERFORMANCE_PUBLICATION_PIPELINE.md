## 实现范围

并发 `2` 允许两个独立、每批不超过 100 条的 ClickHouse INSERT 与各自完整 readback 并行。PG prepare 和 receipt 发布仍使用同一个已持有的 client，按顺序执行；不会并发使用该 client。失败路径等待 `allSettled` 完成后退出，不遗留仍在执行的发布工作。

旧的已发布 closure migration 强制采用并发 `1`，保留原 PG 逐项认证顺序。流水线没有取消正文认证、完整 readback、receipt 或原有失败拒绝条件。

基准入口通过 `BAIZE_PERF_FACT_PUBLICATION_CONCURRENCY=1|2` 显式设置子进程 `BAIZE_FACT_PUBLICATION_CONCURRENCY`，默认值为 `1`。非法值在资源使用和证据锁创建前拒绝。plan 记录数值 `publicationConcurrency`，与 `coverageReuse`、`pagePathBatch` 分开。
