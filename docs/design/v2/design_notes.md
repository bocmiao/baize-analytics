## 二、动效 Motion Tokens
| Token | 值 | 用途 |
|---|---|---|
| `--dur-instant` | 100ms | 按压反馈 |
| `--dur-fast` | 160ms | hover、十字准星跟随、tooltip |
| `--dur-base` | 300ms | 分段控件、主题切换、开关、筛选标签进出 |
| `--dur-slow` | 600ms | 卡片进场、条形增长、访问流滑入 |
| `--dur-draw` | 1200ms | 折线描绘、漏斗和进度条增长 |
| `--dur-count` | 900ms | KPI 数字滚动（ease-out-cubic） |
| `--ease-out` | cubic-bezier(.22,1,.36,1) | 默认进场 |
| `--ease-in-out` | cubic-bezier(.65,0,.35,1) | 位移、切换 |
| `--ease-spring` | cubic-bezier(.34,1.56,.64,1) | 在线人数弹跳、新柱子、筛选标签弹入 |
| `--stagger` | 40ms | 卡片依次进场的间隔（最多 14 级，约 560ms） |
| `--pulse` | 2s | 实时脉冲环、“实时推送”呼吸点 |

**编排**：进入页面时卡片按 40ms 依次上浮 → 折线描绘（延迟 150ms）→ KPI 数字滚动 → 虚线段淡入（1.2s 后）。切换日期或筛选时，卡片先淡化去饱和（160ms），然后重放描绘、条形和数字动画。AI 回答先逐字流出结论，再淡入建议列表和依据标签。

**克制原则**（参照 Ant Design）：所有动效都对应“进场、反馈、状态变化”之一；数字滚动只在首屏和刷新时触发，没有循环闪烁；骨架屏用 1.4s 线性 shimmer。

**无障碍**：遵守 `prefers-reduced-motion: reduce`，所有动画和过渡关闭，图形直接显示终态，数字直接显示终值，打字效果直接显示全文，实时推送也停止。URL 加 `?motion=off` 可以强制关闭。

## 三、可交互演示（在浏览器打开 index.html）
- 顶栏“今天 / 7 天 / 30 天”：看板刷新过渡，然后重新描绘图表、重新滚动数字
- 点任意条形行：新增筛选标签并刷新；点筛选标签：标签弹出并刷新
- 鼠标划过访问趋势：十字准星和 tooltip 跟随（日期、星期、上期值、涨跌、未完结标记）
- ◑ 按钮：深浅主题平滑切换；`?theme=dark` 直接打开深色
- 实时页：每 2.6 秒推送一条新访问，在线人数弹跳，分钟柱滚动
- AI 页和总览洞察条：逐字流出
- 状态页：骨架屏 shimmer，“等待首个浏览”旋转指示
- `?only=<屏幕id>` 单独查看某一屏

## 四、配色补充（参照 AntV 色板“分类色明暗交替”）
分类色顺序：青玉 #2F7D6D（暗）→ 鎏金 #C29A4E（亮）→ 墨灰 #8FA39D → 朱砂 #C2553F → 雾青 #B9C9C2。明暗交替，色弱用户也能区分。深色主题整体提亮一档（#4FB39C / #D9B66A / #E07A63）。涨跌用青玉 / 朱砂，避免红绿在中国语境下的歧义。
