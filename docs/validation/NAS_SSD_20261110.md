# NAS SSD 验证记录（2026-11-10）

本轮验证仓库整理后的 Node 标准版，基线为 `3dac02284c4dee43b891a65c85e8b1da46a1bc7c`，包含本次标准版 capabilities 端点及暗色、平板布局修复。测试为独立内网实例，使用专门的管理员和测试站点。

## 存储与部署

- Linux x64，Docker Compose，Node 24、PostgreSQL 17、Redis 7。
- 通过物理盘、LVM 和挂载点逐层确认数据卷来自 NVMe SSD；DockerRootDir 同样位于该 SSD。
- 应用文件、密钥、PostgreSQL 和 Redis 均使用该 SSD 内的独立绑定目录。仅应用端口绑定到 NAS 局域网地址，数据库和缓存没有发布宿主端口。
- 三个服务均健康，配置了 `unless-stopped`。源码构建及 [NAS Compose 示例](../../deploy/docker-compose.nas.example.yml) 的 `config --quiet` 校验通过。

## 验证边界

本轮运行的是 Node 标准版。没有执行 NAS 整机重启、故障恢复或负载测试，也没有调用外部 AI、搜索、邮件连接器；PHP 和 Lite 未进行本轮运行验收。

真实 tracker 测试的短时间区间返回完整覆盖；“今天”的整日范围仍显示聚合未完成，该显示不作为采集失败或全天数据完整的证据。README 只使用已完成历史区间的 [总览截图](../images/README.md)。

登录凭证、会话、NAS 私有地址和完整运行日志保留在部署者的私有目录，不提交到仓库。
