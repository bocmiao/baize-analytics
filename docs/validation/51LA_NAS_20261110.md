## 已知边界与本轮未运行项

- 旧小时汇总与已发布事实重叠时，`overlapping_legacy_history` 使受影响的历史总值和峰值为 `null`，并给出重叠边界。若该边界不在本月，本月结果可独立保持可用；不能任意舍弃一侧数据后声称历史精确。
- 原始 IP、可用于独立 IP 去重的身份和运营商没有新增采集。已有脱敏网段不能当作独立 IP；IP 与 ISP 未知值保留为空。缺少有效地域来源时保留未知地域，不补造地理分布。
- 最终镜像的地图轮廓已通过桌面、手机及视口恢复后的显示复核；地域库仍未配置，地域统计保持未知，未验证真实地域识别的准确率。
- 预测尚未实现，`forecast.status=not_estimated`，没有填入预测值。
- 日盐模式不提供跨日身份统计和新老访客；历史或明细覆盖不足时不以零替代未知。
- 本轮未运行压力或容量测试，没有新的吞吐量、延迟上限或 SLO 结论。
- 本轮未运行 PHP、Node Lite 的完整回归，也未将新增 Node 标准版报表视为这两个运行方式已同步实现。
