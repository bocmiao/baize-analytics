# 白泽产品界面整理

日期：2026-11-10。运行源码：`b1ed60c`；主要改动提交：`93bde61`。

本轮把工作台聚焦于网站访问分析，使用白泽已有头像和蓝色品牌。统计服务、数据库结构和采集逻辑未改动。

## 界面改动

- 删除概况底部的人工日期备注，移除正常查询下的存储来源、epoch、水位等内部说明。
- 主导航整理为概况、实时、流量、来源、内容、访客、转化、行为、推广、设置。AI、SEO、收入、实验等九个非核心入口退出默认导航；既有路由保留兼容。
- 通知、定时报表和告警收进设置；接口令牌、任务、审计与更新归入高级管理，沿用权限过滤。
- 今日、昨日、预测和同期数据放在一张对比表内，实时人数移至表头。预测仍标明参考程度，计算依据默认折叠。
- 统一蓝白/深色主题、字体、表格、按钮与卡片；图表采用蓝色主线和灰色比较虚线。日期轴保留完整提示，显示标签缩为月日。
- 精简访问明细、事件规则、热图、推广、共享看板、IP 规则、目录规则和站点管理等十二个模块的中英文文案。保留隐私同意、删除影响和不可用数据提示。
- 设置页去掉无效日期筛选和重复外层卡片，改为横向分区。登录及产品入口删除宣传性赘述。
- 手机保留抽屉导航、可滚动表格、日期弹层及焦点返回；概况指标按窄屏重新排列。
