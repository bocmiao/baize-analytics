# 51.LA 功能补齐与 NAS 实机验收

验收日期：2026-11-10（Asia/Shanghai）。运行源码：`80c2e793c12adecf3d2b8e8c68e816e3b6d35b8e`。后续提交只整理本文、功能矩阵与截图。

## 范围与结果

按 [逐项功能对照表](../51LA_FUNCTION_MATRIX.md)核对 Node 标准版，补齐访问明细、日期比较、内容目录、推广管理、事件圈选、热图、分享和站点维护。所有新增入口均接真实接口；演示数据与真实浏览器测试分别保存在独立测试站。

本轮没有创建 PR，直接提交 main。运行环境为 NAS 上的 Node 标准版、PostgreSQL 17、Redis 7；应用、数据库、密钥和 Docker 存储均位于已核实的 NVMe SSD。

## 修复的实际问题

- 访问记录改为服务端筛选、排序与分页；完整 CSV 导出不再局限当前页。支持访客前缀、IP 网段、地域、来源和页面筛选，访问路径与访客历史可展开。
- 地域报表补会话、新老访客与访问质量指标；浏览器及系统版本来自新采集数据。旧数据缺失时不补造。
- 新增目录规则、推广链接持久化、UTM 参数库、本地二维码及渠道逐级分析。
- 事件分析增加次数、人数、人均、参数与多事件趋势。可视化圈选保存规则后，普通访客的真实点击会进入统计。
- 热图可按日期、页面和采集屏幕筛选，叠加真实网页或本地完整截图；同时显示元素点击与滚动深度数据。
- 只读分享新增汇总、趋势、热门页面、来源、设备与地域；五类嵌入图表有服务端实现，不返回访客身份或原始事件。
- 设置页原来提前返回，导致安装检测和移除站点组件不可达，已移入实际渲染区。移除采用可恢复回收站，停止采集并撤销授权。
- 计划、通知渠道和告警原来缺删除入口；删除报表或渠道时已排队通知仍可能发送。现已补入口，并在站点锁内清理依赖及撤销未发送任务，保留已发送历史。
- 录屏初始时间出现负 Unix 秒，现以 `pause(0)` 初始化 rrweb 基准；播放、暂停、拖动、倍速与自然结束同步实际状态。
- 手机访问明细筛选默认收起，仍显示生效筛选；日期弹层支持焦点锁定、Escape、焦点返回和滚动恢复。表格仅在容器内横向滚动。
- 061 历史备份校验接受已发布的两个精确 LF / CRLF 摘要；SQL 文件及已应用迁移摘要未改。见 [换行校验说明](HISTORY_MIGRATION_LINE_ENDINGS_20261110.md)。

5. 手机侧栏打开、选择站点和跳转后收起；日期弹层焦点循环、Escape 返回和恢复滚动均正常。
6. 手机访问记录默认折叠筛选；访客前缀查询从 4 会话筛到 1，会显示生效条件，路径可展开。

8. 保存推广链接、刷新页面后仍存在；复制 URL 与目标 UTM 一致，二维码图像真实加载为 320 × 320。
9. 设置页“检查网页安装代码”“移除站点”在实际渲染的“站点维护”区域可见。
