# 白泽：两套可操作视觉原型

这两套原型是供选择的独立设计方案，尚未替换正式应用。全部数字来自同一确定性模拟数据，不是网站测量结果，也不是生产性能证明。

- A：精致浅色，总览 → 带上下文下钻。首页强调关键变化和主趋势，来源、漏斗、热图、落地页在分析页。
- B：石墨分析工作台。先选指标/维度，再在大图中分析，明细、路径和证据按需切换；保存视图仅存在当前标签页内存，刷新即清除。

## 离线打开

解压 `baize-ui-prototypes-v2.zip`，双击 `index.html`，选择 A 或 B。预览使用同目录经典 JavaScript 和 CSS，无 CDN、外部字体、网络接口、账户或构建步骤。不要单独移动 HTML 文件；保留相邻目录结构。

本云环境 Chromium 策略阻止 file:// 导航，未绕过；实际浏览器验收通过仅绑定 127.0.0.1 的静态服务器，检查没有外网请求。普通桌面浏览器的双击打开未在该受管执行器直接验证。

## 可操作路径

1. 在 7/30 天、PV/UV/转化之间切换；开关上一周期比较，同时更新指标、趋势和每日明细。
2. 主图悬浮查看日期、本期、前期日期、绝对差与变化率。点击固定，Esc 解除；日期明细或图中点可用键盘逐日操作。
3. 点击时间标注查看人工备注；备注不代表因果关系或收益证明。
4. 进入分析，点击来源或落地页形成可撤销筛选，指标、图表与明细真正按演示访客子集重算。返回、刷新保留允许的日期/指标/筛选上下文。
5. 漏斗展示去重访客、首步/上步比例和流失人数；访问时段图显示 Asia/Shanghai 下所选范围的累计 PV。星期列在手机局部横滑中固定，也可用星期/小时选择器精确定位。
6. 查看排序的落地页明细。A 使用排序选择器，B 展开明细后点击列头。
7. 用“预览状态”（B 在“预览选项”中）切换加载、无匹配、错误，观察不同状态；它们是显式演示，不是后台请求。

数据窗口截至 2026-10-10。UV 按窗口访客去重；转化总数是事件次数，转化率使用转化访客/访客。漏斗中间步骤为模拟群组，不声称真实业务追踪。上一周期为等长、不重叠日期，按日期序号对齐，不声称同一天或“今日此时”。
