## 做了什么

按 `docs/design/v2/` 设计稿，只改 React + Vite 前端表现层。标准版和 Lite 共用这套界面；Lite 仍只出现代码里真实存在的报表。后端、追踪脚本、数据模型和接口没有改。

- 设计稿（可交互 `index.html`、浅色/深色截图、`design_notes.md`、动效录屏）放在 `docs/design/v2/`。
- 青玉 / 墨玉 / 鎏金 / 朱砂 token，完整浅色与深色。默认浅色；`?theme=dark` 或顶栏切换后写入 `localStorage`（`baize-theme`）。不跟随系统配色，避免主题在测试里来回跳。
- 图表分类色按稿：青玉、鎏金、雾色、朱砂。涨跌用青玉 / 朱砂。
- 动效 token 与 `prefers-reduced-motion`、`?motion=off`：图表绘入、KPI 数字滚到接口返回的终值、实时脉冲与在线人数弹跳、十字准星提示、筛选标签过渡、骨架屏、AI 回答逐段流出。
- 登录 / 初始化、总览、实时、页面、来源、受众、事件与目标、漏斗与留存、SEO、AI、站点与安装步骤、成员、设置、加载骨架，以及手机底栏。没有对应报表的版本不会凭空多出页面。

角色仍按现有代码：实例管理员或站点 `owner` / `admin` 走管理入口；`analyst` 可写；`viewer` 只读。成员表单不能改 `owner`。没有按设计稿补一套权限矩阵。

## 稿里有、仓库没有、因此没做

- 总览顶部由模型撰写的结论。洞察条只用已有 `overviewInsights` 的第一条事实观察，并链到现有「问白泽」。总览仍不调用模型。
- SEO 健康分、严重 / 警告 / 通过堆叠、浏览器与爬虫 HTML 对照。没有这些字段。Lite SEO 仍是已知路径和粘贴 HTML。
- 安装向导里「等待首个浏览」的轮询。进度只表示当前步骤。
- 离线「显示 23:01 缓存」条。没有缓存接口。
- 表格行上额外的「⊕ 筛选」控件。现有路径和渠道链接已经能筛选；再加文案会改掉测试依赖的可访问名称。筛选标签只给已有 chip 加过渡。
- 对比开关只隐藏前期和变化行的展示，不生成对比数据。前期仍来自现有接口。
- 「永久免费 · 无 PV 额度 · 数据保留由你决定」是设置页静态说明，不是新指标。
