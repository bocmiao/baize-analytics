# 手动自定义搜索分析导入

这是一份白泽自定义聚合模板，不是百度搜索资源平台的原生 CSV，未宣称兼容其当前导出文件，也没有调用或实现百度官方读取 API。百度统计搜索词、SERP 排名和 referrer 不能替代自然搜索展现/排名。实际官方 CSV 样本及接口权限仍未验证。

管理员进入 **SEO → 手动自定义搜索分析 CSV**，下载[空白模板](templates/custom-search-analysis.csv)，按自己有权使用的聚合数据填入以下六列。不会提供演示统计填充模板：

| 字段 | 格式 |
|---|---|
| day | 有效 YYYY-MM-DD 日期 |
| query | 非空搜索词，最长 1,024 字符 |
| page | http/https 完整 URL，hostname 必须与站点 domain 精确相等；不自动接受 www 或子域，不能含凭据或显式非默认端口 |
| clicks | 0 至 Number.MAX_SAFE_INTEGER 的整数 |
| impressions | 安全非负整数且不少于 clicks |
| position | 非负有限平均排名，最多 1,000,000 |

文件为 UTF-8 逗号 CSV，可有 BOM、CRLF、引号内逗号/换行及双引号转义。解码后 CSV 不超过 **5 MiB**，数据最多 **100,000 行**，最多100列，单元格最多8,192字符；JSON请求另有32 MiB硬上限，用于容纳合法CSV引号/换行的JSON转义。当前不支持Excel二进制、分号分隔、千位分隔、公式数值或自动识别供应商格式。

1. 填写“来源说明”，这是用户声明，不是官方来源认证；上传自己的文件。
2. 在六个映射输入框填写文件内的确切表头。表头不能为空、重复或把多个目标字段映射到同一列；其余列不导入。
3. 勾选自定义格式说明，点击“校验并预览”。服务器校验完整文件，只展示前20行及实际行数/范围；非法值使整批失败。
4. 确认后点击“确认导入独立批次”。服务器重新解析原文件，不接受客户端伪造的 parsed rows；同站点相同规范化内容、来源说明和映射的 SHA256 digest 复用旧批次。
5. 点击“查看批次”核对保留的明细，页面最多显示1,000行并明确截断；管理员可“下载安全CSV”取完整批次。导出的公式前缀（含前置空白/换行）被加单引号，避免表格软件执行；下载内容不是原字节文件。

页面URL的查询参数/片段被移除后保存；页面主体或搜索词仍可能含用户提供的敏感内容，不能仅凭聚合格式声称匿名。请只上传有授权、适合保留的数据。原CSV整文件不单独保存，但关键词/来源声明和映射持久化；服务端事务保存批次、行与不含关键词正文的审计，失败回滚。

各批次独立保存，不替换其他日期区间，不自动跨批次/provider求和，避免重叠文件重复计数。数据只进入 `manual_search_imports`/`manual_search_rows`，不写GSC、采集events、PV/UV、身份、订单或SEO因果转化。站点管理员可预览/提交/CSV下载，具有本站read权限的成员可按批次API读取；其他站点拒绝访问。全PostgreSQL备份自然包含这些表，整站JSON/CSV白名单包含这两张独立手动搜索表及批次元数据，仍不包含认证/凭据，不能替代全库恢复。

接口前缀为 `/api/sites/:siteId/manual-search`：GET列表；GET `/template`；POST `/preview` 与 `/commit` 接收 `{csv,label,mapping:{day,query,page,clicks,impressions,position},customTemplateAcknowledged:true}`；GET `/:id`；GET `/:id/csv`。列表最多100批且有truncated标记；详情最多1,000行，报告完整rowCount。preview和commit均要求本站admin，不存在自动购买/申请外部凭据行为。

本地真实PG和Chromium上传/映射/预览/幂等/安全下载已经专项执行；不代表百度真实账号、原生CSV格式或外部API验收，完整不可变主线计数由根验收记录另列。
