## 当前产品

- 标准版使用 PostgreSQL，Redis 可配置；严格 ClickHouse 权威/历史链有独立协议，不因原生运行包而简化为普通 PG 备份。
- Lite 是同一仓库、AGPL 许可证、品牌、界面及 tracker 的单进程 SQLite profile，具有事务采集、固定身份重试、查询预算、任务租约、留存/删除、签名备份、离线迁移和手动 HTML/BYOK 能力。高级漏斗/路径/回放/热图/分布式入口按能力限制，不能静默伪造结果。
- 初始化采用本机私有一次性凭证，管理员、首会话、终态原子提交。删除用户或复制旧凭证不会开放初始化；恢复旧空用户备份也阻止公开抢占。旧账户升级正常登录，不自动修改账户。
- 网页环境检查受安装凭证或管理员会话保护，只输出非秘密摘要；不能安装 Node、托管服务或验证 HTTPS 证书。响应中断后先核实初始化/站点状态。
- 日期边界、复制结果、异步导出刷新纳入回归。Lite 页面详情采用站点授权和共享精确统计；过期/缺少会话前缀返回未知值，不替换成零。总览保持品牌，按实际内容宽度调整趋势/来源布局，支持手机、键盘展开与减少动画偏好。

## 部署与维护

三个入口见 [新手部署](deployment-methods.md)：Docker 一键；包含编译物和依赖的 Node-ready 项目包；附带 Node 的 Linux x64 包。后两者不需要在部署机 clone 或编译。源码、只有 dist 的压缩包、Git bundle 和应用镜像 save 用途不同，不能当作完整运行包。

数据、密钥、配置和备份在发布目录及公开网站根目录之外。服务由独立进程托管，不依赖 Codex/SSH。原生标准版维护使用官方 PG 客户端，仅支持 PG-only，严格 CH 模式提前拒绝；升级先验证新的数据库/目录候选，由操作员明确切换，失败保留源和恢复点。恢复回放最新独立删除日志，撤销旧会话与临时授权，用户用原密码重新登录。详见 [原生维护](release-native-ops.md)、[Lite](lite-deployment.md)、[离线迁移](lite-migration.md)。

原生包目标为 Linux x64；Windows、macOS、ARM、Alpine、宝塔实例、真实域名 HTTPS 和跨物理机灾备没有完整实测，不标为已验。真实 Google/付费 SERP、邮件、SSO、模型质量和微信真机仍需外部联调；模拟 transport 不冒称真实付费调用或模型质量证明。
